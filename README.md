# Google Homepage Clone

A responsive Google Homepage Clone built using **HTML5** and **CSS3**. This project recreates the clean and modern interface of the Google homepage, focusing on responsive design, layout, and styling.

## 🚀 Features

* Responsive design for desktop, tablet, and mobile devices
* Clean and modern Google-inspired user interface
* Responsive navigation bar
* Search bar with Material Symbols icons
* Interactive hover effects
* Footer layout similar to Google's homepage
* Built using Flexbox for responsive alignment

## 🛠️ Technologies Used

* HTML5
* CSS3
* Google Fonts (Roboto)
* Google Material Symbols
